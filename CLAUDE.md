# Lord Hill Consulting — session instructions

**⚠️ This repo IS the live website, and this repo is PUBLIC.** lordhillconsulting.com serves from it via GitHub Pages (+ Cloudflare DNS/HTTPS). Anything pushed to `main` goes live to the public within minutes, and every file in this repo is publicly readable. Never push work-in-progress to `main` — use a branch, or confirm with Matthew before pushing. Never commit internal notes, business strategy, credentials, or client information here.

## Ground rules

- Brand voice: professional, plainspoken, local. No hype.
- The site is a self-contained static page — no build step. Keep it that way.
- The contact form's current behavior is intentional; don't add backends or third-party services without being asked.
- Cloud/mobile sessions: edit, commit, push (respecting the live-site warning above). Desktop sessions: `git pull` before starting work.
- Internal business context and prospecting work live in the **private** `lhc-prospector` repo, not here.
